### 7.3 两个模型的对比要点（Theorem 3.2′ 的直接证据）

| 指标 | TiLamb+LoRA | Qwen+LoRA |
|---|---|---|
| ISR 范围 | 0.0041 – 0.0082 | 0.0401 – 0.0539 |
| 相对人类 (0.0043) | 0.94× – 1.90× | 9.31× – 12.55× |
| ρ(压缩率, ISR) | −0.8214 | **+0.6429（反向）** |
| 音节产出随预算增长 | 20.4 → 153.2（**7.50×**） | 6.5 → 42.5（**6.57×**） |
| compression_syll 变化幅度 | 0.0575 → 0.4112（**7.15×**） | 0.0171 → 0.1135（**6.64×**） |
| ISR 波动幅度 | 2.01× | 1.35× |
| `truncation_rate` | 1.000（T≤128）/ 0.993（T≥192） | **全部 1.000** |

**三条可直接引用的结论**
1. **同实验内的解离**：`compression_syll` 变化 6.6–7.2×（"说多少"被预算完全操控）而 ISR 仅变化 1.35–2.01×（"多合法"几乎不动）—— 说明**控制输出预算能控制生成量，但控制不了正字法合法性**。
2. **藏文产出效率差距**：在同样 T=256 下 TiLamb 产出 153.2 音节 vs Qwen 42.5 音节（**3.60×**）。折算 `syll/token`：TiLamb ≈ 0.598 vs Qwen ≈ 0.166 —— Qwen 约 **72%** 的生成预算被非藏文内容占用。这是 Qwen 高 ISR 的根因量化。
3. **⚠️ "压缩"实际未被操纵**：全部 14 档的 `truncation_rate` 都 ≈ 1.00，意味着模型的自然长度**超过**了每一档的上限，即每一档都是"被截断"而非"自然停止"。因此 7 档实质是**"保留多长前缀 / 给多大输出预算"**的扫描，**不是压缩率的扫描**。动笔时须改称**输出预算不变性（output-budget invariance）**，旧 Theorem 3.2 的速率形式严格说是 **untested** 而非 falsified。

### 7.4 ⚠️ 已知缺口

`chrf` / `rougeL` / `bleu4` 在全部 14 档中**均为 null** —— 长度扫脚本当时未记录逐档语义指标。因此**无法在本次实验内**验证"语义层随 L 变化"的一半（Theorem 3.2′ 的 IB 层分支）。若论文需要该曲线，须**补跑带 `--metrics` 的长度扫**。
