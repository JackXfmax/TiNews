## 0. 为什么加 Task 3（论文定位）

TiNews 原双任务（Task 1 分类、Task 2 句子级续写）只覆盖"判别"与"局部生成"。
新闻理解还差两块：**全局压缩（摘要）** 与 **要素抽取（关键词）**。新增 Task 3 把 TiNews
从"分类 + 续写"升级为"理解 + 生成"三位一体，且与 Task 1/2 共享同一藏文新闻语料域，
增强 benchmark 的体系性，而非另起炉灶。

## 1. 两个数据来源与互补性（直接回答"能否互补"）

### 1.1 BodSUM-6000（主评测集 · 标准单篇）
- 位置：`C:\Users\机械革命\Desktop\BodSUM-6000.csv`，标准 CSV（`ID, Title, SUM, Text`）。
- 规模：6000 条藏文正文 + 人工摘要 + 标题。
- 质量：官方声明经严格主观 + 客观评价；我抽样前 12 行确认藏文规范、摘要简洁流畅、无聚类格式噪声。
- 形态：单篇、干净、独立（无聚类、无关键词字段）。

### 1.2 Ti-SUM（扩展维度 · 聚类 + 关键词）
- 位置：`C:\Users\机械革命\Desktop\Ti-SUM`，130 个 txt，同文件 = 同聚类（同事件多报道）。
- 规模：992 条 `body` + `title`(=人工摘要) + `keywords`(藏文关键词，། 分隔)。
- 形态：聚类、带关键词、格式噪声大（6 文件无 title、18 条无摘要、734/992 有关键词 → 26% 缺失）。

### 1.3 互补性矩阵

| 维度 | BodSUM-6000 | Ti-SUM | 互补结论 |
|---|---|---|---|
| 数据形态 | 单篇标准 CSV | 聚类多文档 txt + 关键词 | BodSUM = 干净主集；Ti-SUM 补"同事件多报道"与"关键词抽取" |
| 规模（清洗后） | 5945 | 992 | BodSUM 提供统计力；Ti-SUM 为扩展 |
| 质量管控 | 严格人 + 机评（官方声明） | 26% 关键词缺失、6 文件无 title | BodSUM 主评测更可靠；Ti-SUM 需清洗（已完成） |
| 覆盖任务 | 仅生成式摘要 | 摘要 + 关键词抽取 + （隐含）多文档摘要 | Ti-SUM 补 BodSUM 缺的关键词与多文档维度 |
| 泄漏风险 | 单篇 → 随机切分安全 | 聚类 → 必须按聚类切分 | 两者均已做防泄漏切分 |

**结论：二者不是冗余，而是互补。**
- **BodSUM-6000** 作为"标准、干净、单篇、大规模"的**主摘要基准**——统计力强、结论可靠，是 Task 3 的主力评测集。
- **Ti-SUM** 作为"真实、聚类、带关键词"的**扩展基准**——补上 BodSUM 没有的**关键词抽取**与**同事件多文档摘要**两个维度。
- 二者统一归入 Task 3，互不替代。

## 2. Task 3 子任务划分

- **3a 生成式摘要（主）— BodSUM-6000**：给定 `Text` → 生成 `SUM`。主评测集 test = 594。
- **3b 关键词抽取 — Ti-SUM**：给定 `body` → 抽取 `keywords`（། 分隔多标签）。可用 734 条（26% 缺失须注明）。
- **3c 聚类 / 多文档摘要 — Ti-SUM**：给定同聚类多文档 → 生成该事件摘要（`title` 作参考）。按聚类切分，test = 90。

## 4. 评测协议（复用 Task 2 口径，保证可比）

- 指标：BLEU-4（**按音节切分**，§6.3.5）、chrF++（字符级）、ROUGE-L、ISR/SCR（藏文正字法，§6.3.3）、可选 COMET（G5，单参考受限但可算）。
- 解码：统一 §6.3 主协议（beam = 4, `no_repeat_ngram_size` = 3, `length_penalty` = 1.0, seed = 42）。
- 跨 tokenizer：若引入 mT5（G4）做摘要 teacher PPL，用 **bits/藏文字节** 桥接（同 §6.8，分母同口径）。
- 关键词抽取（3b）：藏文音节级 F1 / 精确匹配 / 部分匹配（། 分隔集合的 Jaccard）。

## 6. 实验排期（GPU · 分阶段 · 非 P0）

- **基线**：抽取式（lead / 藏文适配 TextRank）、seq2seq（mT5-base，与 G4 同架构口径）、TiLamb-7B + LoRA 微调做摘要。
- **评测**：3a 主集 + 3b/3c 扩展，结果填大纲 §7.5 与台账 §7。
- **与 G4/G5 协同**：mT5 已在 G4 脚本；COMET 在 G5。Task 3 摘要生成指标可复用同一生成链，避免重复造轮。

## 7. 学术红线（写入正文 / Limitations）

1. **不夸大 BodSUM 质量**：仅抽样 12 行 + 官方声明，全文质量审计待做；不得写"已严格验证全部 6000 条"。
2. **跨 tokenizer PPL 不直比**：用 bits/藏文字节桥接（同 §6.8）。
3. **KL 小 ≠ 质量好**（沿用 §8.4.7）。
4. **Ti-SUM 26% 关键词缺失须如实声明**：3b 仅在 734 条上评测，不得假装全覆盖；缺关键词样本在关键词子任务中剔除并注明覆盖率。
5. **Task 3 不抢 Task 1/2 的卖点**：它是对 benchmark 覆盖面的扩展，不是"又一个工程组合创新"。
