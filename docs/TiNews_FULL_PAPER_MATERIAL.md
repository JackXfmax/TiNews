# Part 1 · 完整论文大纲（rev4）

> rev4 = rev3 + **解码协议** + **截断 KL 理论框架** + **藏文特有的 ISR 诊断量**。

## 一、Title & Abstract
**Title**：*TiNews: A Benchmark for Tibetan News Classification, Continuation, and Summarization*

摘要末句**可按下列实测口径加一句**（措辞须与 §8.4.7 一致）：
> *"我们进一步给出藏文续写的标准解码协议，并证明截断解码的偏差恒等于 −log Z_t：在藏文上实测近确定步占比 α = 0.363，据此 top-k 的最坏步失真被放大 1.57 倍，实测其每步 KL 为 top-p 的 1.7 倍。"*

❌ **不得**写成"采样解码在藏文上的流畅性代价更高"（ISR 预测已被证伪），也**不得**声称某解码策略全面最优。

## 二、Introduction（贡献点）
(1)–(6) 同 rev3（略：基准构建、7 类分类、句子级续写、overnmental 三层基线…）。

**(7)【rev4 新增·按实测改写，措辞不得回退】**
TiNews 给出藏文续写的**标准解码协议**与**截断偏差分析框架**。证明截断解码相对模型分布引入的偏差恒等于 `KL(q_t‖p_t) = −log Z_t`（Z_t 为截断 support 的概率质量），并给可证伪推论：top-p 是唯一保持**常数 KL 预算**的截断族，top-k 的预算随分布尖锐度波动，在近确定步占比 α 的语料上其最坏步失真被放大 `1/(1−α)` 倍。

**实测支撑（须照此写）**：TiLamb-7B 上，49,674 个 teacher-forced 步实测 α = 0.3627（→ 放大因子 **1.569**）；top-k 每步 KL 显著高于 top-p（**0.0587 vs 0.0342**），预算波动远大于 top-p（高熵/低熵比 **330× vs 4.2×**）。

**同时如实报告的反证（不得省略）**：原预测"采样类解码在藏文上的流畅性代价（ISR）高于 beam 类"**未获支持**——实测采样 ISR（0.0044–0.0046）并不高于 beam（0.0045–0.0055）。

> ⚠️ **红线一**：贡献点 (7) **不能**写成"我们对比了 8 种解码策略"。对比不是贡献，**恒等式与放大因子 1/(1−α) 才是**。
> ⚠️ **红线二**：不得以 ISR 差异作为本贡献点的证据（已证伪）；不得声称 EGD 全面最优（EGD 的 BLEU 低于 top-p+T=0.7）。

## 六、Evaluation Protocol

### 6.1 分类任务
同 rev3（6.1.1 四种上下文设定 / 6.1.2 指标 / 6.1.3 三层基线 / 6.1.4 特征）。

### 6.2 续写任务
**6.2.1 任务定义**：给定前 k 句生成第 k+1 句；句子级归一化 PPL。

**6.2.2【rev4 必须写明的澄清】PPL 不经过解码。**
句子级 PPL 是 **teacher-forcing 下的条件似然**：`PPL = exp(−(1/|y|) Σ_t log p_θ(y_t | x, y_{<t}))`，其中 `y_{<t}` 是**参考前缀**而非模型自回归输出。因此 PPL **与任何解码策略无关**。必须显式写入正文：reviewer 极易混淆似然评测与生成评测；且它自然引出关键区分——**teacher-forced 似然 ≠ 生成质量**。

**6.2.3 人工评测**：四项（流畅性 / 连贯性 / 信息量 / 藏文正字法正确性），1–5 分。

### 6.3 Canonical Decoding Protocol（标准解码协议）
**6.3.1 为何必须写死**：一旦报告任何基于生成文本的指标，解码策略即成为混淆变量——同一模型 greedy 与 top-p=0.95 下的 BLEU 差异常大于模型间差异。

**6.3.2 主协议（主表所有生成指标一律采用）**
| 项 | 取值 |
|---|---|
| 方法 | Beam search, **B = 4** |
| `length_penalty` | 1.0 |
| `no_repeat_ngram_size` | 3 |
| `max_new_tokens` | 参考句长 p95 上取整 |
| EOS | 遇 `།` 或换行终止 |
| 随机性 | 确定性，不采样 |
| seed | 42 |

> 选 beam=4：greedy 多样性过低（distinct-2 塌陷），top-p 在**单参考** BLEU 下被系统性低估（每条续写仅 1 条参考）。

**6.3.3 藏文特有的生成流畅性诊断量**
| 量 | 定义 | 作用 |
|---|---|---|
| **ISR**（Invalid Syllable Rate） | `1 − 合法音节数 / 生成音节总数` | 是否产出不合法/不闭合音节串 |
| **SCR**（Syllable Closure Rate） | 以 `་`(tsheg) 或 `།` 正确终止的音节占比 | 音节边界完整性 |
| **E[−log Z_t]** | 平均截断 KL 预算（Lemma 1） | 解码相对模型的系统性偏离 |
| **KL_p99** | 逐步 `−log Z_t` 的 99 分位 | 检验放大效应 |

> **实现说明（已校准）**：ISR/SCR 由**确定性藏文音节槽位语法判定器**（`syllable_slots_v3.parse`）计算——按 前加字/上加字/根字/下加字/元音/后加字/再后加字 七槽位解析。已在 **3.6M 人类音节**校准：新闻正文 ISR≈0.6%、续写参考 ISR≈0.4%、SCR≈0.88（**不过杀合法藏文**）。中心点统一用 **ISR**，**不用** `1−SCR` 的松口径。78 个边缘槽位组合仍专家审校中。

**6.3.4 人工评测执行约束**：必须只在主协议（beam=4）样本上执行；否则评分依赖 seed 不可复现。

**6.3.5 藏文生成指标的 token 化约定**（必须写明）
藏文**无词间空格**，BLEU 的 token 单位不唯一：
- **BLEU-4 一律按音节切分**（以 `་` U+0F0B tsheg 为分隔符，剔除句末 `།`）；
- **chrF++ 用字符级**（byte-level 回退），跨切分可比；
- 论文与开源代码**必须显式声明切分方式**，否则他人无法对齐。

### 6.4【Task 3】摘要与关键词抽取
**6.4.1 三个子基准**
- **3a 生成式摘要（主，BodSUM）**：Text → SUM；5945 条（train 5351 / test 594）。
- **3b 关键词抽取（Ti-SUM）**：body → keywords（། 分隔多标签）；可用 734 条（26% 缺失）。
- **3c 聚类/多文档摘要（Ti-SUM）**：同聚类多文档 → 事件摘要（`title` 作参考）；test 90 条。

**6.4.2 互补性**：BodSUM 提供"标准干净单篇大规模"主摘要基准；Ti-SUM 补关键词 + 同事件多文档维度。二者不冗余。

**6.4.3 防泄漏切分**：BodSUM 随机 90/10（seed 20260930）+ 正文精确去重（54 条重复）；Ti-SUM 按 cluster(文件) 切 90/10，同事件不跨集。

**6.4.4 评测协议**：BLEU-4（音节切分）、chrF++、ROUGE-L、ISR/SCR、可选 COMET；解码统一主协议；跨 tokenizer 用 bits/藏文字节桥接；关键词用音节级 F1 / ། 分隔集合 Jaccard。

### 8.4【理论核心】截断解码的 KL 偏差分析

**8.4.1 记号**：第 t 步 `p_t(y) = p_θ(y | x, y_{<t})`，截断解码取 support `S_t ⊆ V` 并重归一化：
```
q_t(y) = ( p_t(y) / Z_t ) · 1[ y ∈ S_t ],    Z_t = Σ_{y ∈ S_t} p_t(y)
```

**8.4.2 Lemma 1（截断偏差恒等式）**
```
KL( q_t ‖ p_t ) = − log Z_t
```
**证明**：
```
KL(q‖p) = Σ_{y∈S} q(y) log( q(y)/p(y) )
        = Σ_{y∈S} (p(y)/Z) log( (p(y)/Z) / p(y) )
        = Σ_{y∈S} (p(y)/Z) log(1/Z)
        = −log Z · (1/Z) Σ_{y∈S} p(y)
        = −log Z .   ∎
```
> 解读：偏差**只由被保留的概率质量 Z_t 决定**，与词表大小、token 身份无关——极干净的单参数刻画。

**8.4.3 Corollary 1（greedy 的偏差即其 NLL）**：greedy 是 `S_t = {ŷ_t}` 退化情形，`q_t = δ_{ŷ_t}`，故 `KL = −log p_t(ŷ_t)` = 该步负对数似然。因此 **greedy 序列的累计截断偏差 = 其 teacher-forced 总 NLL**。这解释 greedy 为何在单参考 BLEU 与 PPL 上一致最优、多样性必然最差：它把全部预算用于最大化似然。

**8.4.4 Proposition 2（top-p 的常数预算性质）**：top-p 取满足 `Z_t ≥ P` 的最小概率降序前缀，`KL_t = −log Z_t ∈ [0, −log P]`，尾部分布连续时 `Z_t → P`，故
```
KL_t → − log P     （常数，与 t 无关）
```
top-k 固定 `|S_t| = k`，`Z_t = Z_t(p_t)` 依赖分布尖锐度，KL 预算随 t 波动。

**8.4.5 Proposition 3（top-k 的最坏步放大）**：设近确定步（`p_max ≥ 1−ε`）占比 α，其余为平坦步。相同期望 KL 预算下：
```
KL_worst(top-k) = ( 1 / (1 − α) ) · KL_worst(top-p)
```
**推导**：top-k 在近确定步 `Z≈1, KL≈0`（预算浪费），平坦步预算全部释放，设其 KL 为 `L_B`；则 `E[KL]_topk = (1−α)·L_B`。top-p 全程 `KL ≡ L_P`，`E[KL]_topp = L_P`。令期望相等：`L_P = (1−α)·L_B ⟹ L_B = L_P/(1−α)`。∎

> **可检验推论**：α 越大，top-k 最坏步失真越放大。藏文音节级生成中句末 `།`、固定套语、音节内部高可预测位置占比高，预期 α 显著偏大。**α 可从 val 集 teacher-forced 的 `p_max` 分布实测（取 `p_max ≥ 0.9` 的步占比）**。

**8.4.6 EGD（Entropy-Gated Decoding）——理论导出而非工程拼凑**
由 Lemma 1，合理解码应使 `KL_t` 各步近似恒定。定义门控：
```
mode(y<t) =  argmax              if  H(p_t) ≤ θ_low
             sample from S*(h*)  if  H(p_t) ≥ θ_high
             beam-B              otherwise
```
其中 `S*(h*) = argmin_{|S|} { S ⊆ V : H( p_S / Z ) ≥ h* }` 为最小充分 support。
**θ 不网格搜索**，取 val 集 teacher-forced 熵分布**分位数**（`θ_low = q20`，`θ_high = q80`），零额外超参、完全可复现。
> ⚠ 写作必须先给**原则**（恒定 KL 预算），再给算法。EGD 的价值来自 Lemma 1 导出的原则，不是"又一个门控 trick"。

**8.4.7 EGD 实测与受限口径（定稿）**
α 实测 **0.3627**（val 集 49,674 个 teacher-forced 步中 `p_max ≥ 0.9` 占比）→ **1/(1−α) = 1.569**；θ = (q20, q80) = (0.0904, 3.2079)。

### §3.1 续写（Lemma 1 放大因子）

### §3.2 摘要扩展：两层分解与 Theorem 3.2′

> v6 曾以 Theorem 3.2 声称「`v_0(L)` 随 `L` 减小单调上升」；七档长度扫**证伪**该速率形式（证伪证据完整保留 §3.2.2 与 Limitations 5，不删）。本节给出取代它的正面定理——definition / theorem 级、**已被数据证实**的可检验结果。

**记号.** 藏文音节语法 `G`（确定性槽位语法 `syllable_slots_v3`）：音节为槽位元组，合法性 = 满足槽位约束。音节字母表 `Σ`，上下文 `c` 下合法集 `A(c) ⊆ Σ`。摘要 `S = (s_1,…,s_L)`，`L` 为音节预算；`Y` = 须保留的任务信息；模型 `M` 的音节级条件分布 `q_θ(·|c_j)`。

**Definition 1（正字法违反指示与 ISR）**
```
e_j ≜ 1{ s_j ∉ A(c_j) },    ISR(S) ≜ (1/L) Σ_{j=1}^{L} e_j
```

**Definition 2（字形接地赤字 γ）** top-1 / beam MLE 解码下
```
γ(M) ≜ E_{c∼C} [ 1{ argmax_{s∈Σ} q_θ(s|c) ∉ A(c) } ]
```
（采样解码下取质量式 `γ_mass(M) ≜ E_c[ q_θ(Σ \ A(c) | c) ]`，二者同向）。`γ(M)` 仅由 **(词表, 预训练权重)** 决定——即模型的**字形接地**程度。

**Definition 3（生成失败的两层分解）**
- **语义 / IB 层**：压缩后保留多少任务信息。受 rate-distortion 支配——为保留 `I(Y;S) ≥ i`，需 `L ≥ L_min(i) ≜ i / h_eff`（`h_eff` = 每音节有效信息量）。可测：ROUGE-L / BLEU-4 / chrF 与**产出量**。
- **正字法 / 字形层**：音节是否合法。受 `γ(M)` 支配。可测：ISR / SCR。

**结构性要点.** IB 约束作用在 **token / 语义流**上；音节正字法合法性是对 token 的**字形实现**的约束，**位于 IB 语义层之下**。故两层由不同对象支配（`L_min(i)` vs `γ(M)`）且**渐近独立**——这是本节实质主张。
> ⚠️ **措辞审慎**：严格说适用于"与语义正交的字形轴"（藏文音节常跨多个子词 token，是 supra-token 而非 sub-token）。

**Theorem 3.2′（正字法瓶颈位于 IB 层之下：压缩不变性）**
假设：
- **(A1)** token-MLE 解码（greedy / beam）：按 `q_θ(·|c)` 取 argmax / beam；
- **(A2)** **字形接地的位置平稳性**：合法集 `A(c_j)` 与"合法 vs 非法候选的序关系"由 `q_θ` 与 `G` 决定，不依赖位置 `j`，也不依赖剩余语义预算。

则对长度预算 `L`：
```
ISR(M, L) = γ(M) + ε(L),    E[ε(L)] = 0,    Var[ε(L)] = γ(M)(1 − γ(M)) / L
即 ISR(M,L) = γ(M) + O_p(L^{−1/2}),   无系统性单调漂移
记压缩率 ρ（随 1/L 增大）：∂ ISR(M) / ∂ρ ≈ 0
Δ_ortho(M) ≜ ISR(M) − ISR(human) ≈ γ(M) − ISR(human)
```
> **→ 正字法赤字对压缩预算不变，仅由基座字形接地决定：压缩既不能诱发、也不能修复它。**

**证明梗概.** 在 (A1) 下 `e_j = 1 ⟺ argmax_s q_θ(s|c_j) ∉ A(c_j)`。由 (A2)，`{e_j}` 为（近似）可交换 Bernoulli，共同均值 `γ(M)` —— 预算 `L` 只约束"选哪些内容"（IB/RD 层），不改变字形层上合法 vs 非法的序关系。故 `ISR = (1/L)Σ_j e_j` 是可交换指示变量的样本均值：Hoeffding 得 `ISR − γ(M) = O_p(L^{−1/2})`，期望 0（**无漂移项**）。∎

> **诚实声明（不可删）.** (A2) **不是**第一原理导出，它是本定理的实质断言，由七档长度扫**实证验证**。被证伪的 Theorem 3.2 预测的正是那个"漂移项"；长度扫拒绝了该漂移项，从而把 claim 从"压缩伤害正字法"翻转为更强的"**正字法失败位于压缩层之下**"。**正文不得写"已证明"，须写"在实证支持下的 (A2) 之上"。**

**Corollary 3.3（跨任务不变性 · 任务适配不可修复性）**
因 `γ(M)` 仅为 `(词表, 预训练权重)` 的函数：
- **(i) 跨任务不变**：压缩—生成轴上（续写 vs 摘要）预测同量级且均 ≫ 人类 → 实测 Qwen 0.0648 / 0.0462；TiLamb 0.004 / 0.0051 ✅
- **(ii) 对任务适配鲁棒**：低秩适配器可重塑语义条件，但在冻结的基座嵌入张成空间内**无法创建**基座词表中不存在的合法音节流形 → `γ` 不变。实测 Qwen+LoRA 0.0462；换正确 chat template 重训仍 0.035 ✅
- **(iii) 对 prompt 格式鲁棒**：`γ` 是解码层属性，无格式依赖 ✅

**几何注记.** 合法藏文音节在发射单纯形上占据**测度稀疏且结构化的子集**（槽位填充受组合约束）。"字形接地" = 基座嵌入空间中存在相干子流形，其经 LM head 的像集中于该子集。未接地基座中，藏文码位散落于 byte-fallback 与跨脚本共享区域（实测与 Odia / Lao / Devanagari 系字形共现），该流形不存在，argmax 无法被约束其上 → 赤字**在地板处饱和**，与预算无关。

# Part 4 · Limitations（10 条，定稿口径）

1. **覆盖范围：diagnostic testbed，非 comprehensive suite。** 沿"理解—压缩—生成"轴线设四个探针；**不宣称**覆盖全部藏文新闻问题。未纳入：NER、关系/事件抽取、机器翻译、QA/阅读理解、立场/情感/事实核查、多模态、方言鲁棒性、摘要**事实一致性（幻觉）**。
2. **数据集：部分为既有资源。** 主集 BodSUM-6000 为**已发布既有数据集**，未发明新数据；贡献在跨任务整合、防泄漏切分去重、以及正字法与指标诊断。且 BodSUM 仅经抽样审计（12 行）与官方声明核对，**未做全量 6000 条质量审计**，不对参考摘要整体质量作保证。
3. **Ti-SUM 统计力有限。** test 仅 **90 条**，关键词标注 **26% 缺失**（3b 实际仅 734 条）。意义在补"关键词 + 多文档"维度，非大样本结论。
4. **ISR 判定器仍有边缘组合待专家裁定。** 已在 **3.6M 人类音节**校准（新闻 ISR≈0.6%、参考 ISR≈0.4%、SCR≈0.88，不过度判杀）；但 **78 个边缘槽位组合**（冲突 26 + 未见 52）审校中。→ **相对比较稳健，绝对 ISR 可能微移**。
5. **自我证伪：Theorem 3.2 的"长度依赖"子推论不成立。** 七档长度扫未支持"压缩越大 ISR 越高"：Qwen 全程 9.3×–12.5× 人类、Spearman **+0.643 反向**、波动仅 1.35×。已做伪影排查（人类参考同长度硬截 ISR 仅 0.0043→≤0.0047），**截断伪影不足以解释**。**据此撤回**速率形式 claim，改以下述更稳健陈述：
   > 藏文正字法能力主要由**基座预训练**决定，压缩率只是**二阶效应**。（= Theorem 3.2′）
   本瑕疵如实报告，未作数据层面修饰。
6. **生成质量结论暂不含人类语义偏好。** 目前限于结构/重叠指标（ISR / SCR / BLEU-4 / chrF++ / ROUGE-L）。母语者人工评测（200 条 × 3 评分者 × 4 维度）**投稿时尚未完成**，故不含语义偏好胜率类结论。
7. **失败根因诊断已部分量化。** 以 `syll/token` 量化藏文产出效率（TiLamb 0.598 vs Qwen 0.166，Qwen 约 72% 预算被非藏文占用）。**仍未量化**：token 级嵌入分布 / 跨脚本码位共现的细粒度分析，及 `γ` 的直接估计（需逐位置合法性标注）→ future work。
8. **解码分析近似的适用边界。** Lemma 1 放大因子 `1/(1−α)` 建立在"近确定步/平坦步"二分类近似下（α = 0.3627）。该近似在 **α → 1** 时最敏感，高度确定的解码场景需谨慎。
9. **评测口径的两点已知偏差。** ① **BodSUM 强抽取偏置**：参考摘要 **96.2% 音节直接来自原文**（词级 92.99%），衡量的是"选句与压缩"，对抽象改写区分度有限；**生成长度是强混淆变量**（未控长度会得出误导性排序）。② **ROUGE-L（LCS 型）系统性偏好连续抄写**，控长后仍偏抽取系统 → 须 chrF++ 与 ROUGE-L 并报且关键比较控长。
10. **困惑度不可跨词表直比。** 唯一可比为**每藏文字节比特数**（`CE_sum / N_syll`，共用分母 485,286）。该口径下通用模型仍更低（Llama 0.673 < TiLamb+LoRA 1.233 < Qwen 1.251 < base 1.333）→ 藏文专门化在困惑度维度**仍有 headroom**。本文**未宣称**藏文专门化整体优于通用，所有结论**分维度**陈述。

- 每条续写**仅 1 条参考句**，单参考 BLEU 对采样类解码存在系统性低估 → 同时报告 chrF++ 与多样性指标，主协议不用采样。BERTScore（CINO 句向量）受单参考约束且本期未实算，留待未来工作。
