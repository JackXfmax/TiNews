## 0. 一句话 thesis（整篇立在这句，v5→v6 不变）

通用大模型在藏文新闻上存在**系统性的结构级失败**——它们违反藏文音节正字法、且压缩失当；而这种失败用常规 PPL / BLEU **根本看不见**。TiNews（诊断台）+ IB/KL 解码框架（理论）把它**暴露并解释**。

卖点是**一个可被证伪的科学主张 + 一套解释它的理论**，不是"我们做了 3 个任务"或"数据集更大"。

## 2. 故事五幕（按此顺序讲）

**① 动机：现有评测的盲点。** 藏文是低资源、强正字法约束语言。现有基准只"训分类器/算 BLEU"，证不出模型是否真懂结构。实证锚点：Llama 续写 PPL 最低（1.99）却 26.9% 音节非法（ISR 0.269）。→ 立论：**PPL 低 ≠ 藏文好**（呼应"KL 小 ≠ 质量好"红线）。

**② TiNews 不是 3 个任务，是"压缩—生成主轴"的 4 个探针。** 分类=能否读结构；续写=能否局部生成且守音节约束；摘要=能否全局压缩且守约束+保信息；关键词=能否抽信息骨架。强调是**同一轴线在 4 个粒度上的采样** → unified testbed，非数据集拼盘（摘掉"工程组合"指控）。

**③ 理论：IB/KL 解码框架 + 生成失败的「两层分解」（独立公式见 §3）。** 把生成看成"长度约束下的信息瓶颈"。关键的新视角是：**压缩（语义/IB 层）与正字法（字形层）不在同一个表示层上** —— 音节合法性是对 token 的字形实现的约束，位于 IB 之下。续写的 KL 预算（§8.4 / Lemma 1）推广到摘要的全局压缩，给出 rate-distortion 下界 `L_min(i)=i/h_eff`；而 **Theorem 3.2′** 给出正字法层的核心结果：赤字 `Δ_ortho` 对压缩率不变、仅由基座字形接地 `γ(M)` 决定（故跨任务不变、LoRA 补不上）。

**④ 实证：跨任务系统性失败（全文高点，v5 时为预测 → v6 已实测证实）。**
- 续写零样本：Llama ISR **0.269**、Qwen 0.0648 ≫ 人类 0.00384；TiLamb+LoRA **0.004** ≈ 人类。
- 摘要同款 LoRA 后：Qwen ISR **0.0462** ≫ 人类 ~0.0057；TiLamb+LoRA **0.0051** ≈ 人类。
- **一致性（核心论点已立）**：通用 7B 在「续写」与「摘要」两任务上均系统性违反藏文正字法（ISR 高于人类一个数量级），且该失败**对任务监督微调（LoRA）鲁棒**；藏文专门化 7B 在两种任务下 ISR 均≈人类。
- ⚠️ **仍守红线**：分维度陈述，**不写「藏文专门化整体优于通用」**。困惑度维度 bits/藏文字节仍通用最低（Llama 0.673 < TiLamb+LoRA 1.233 < Qwen 1.251 < base 1.333），headroom 存在。

**⑤ 意义：可迁移 + 方法论诚实。** TiNews 是**诊断框架**不是 leaderboard——leaderboard 会过时，诊断方法能迁移到任意低资源约束语言（藏文是 case study，非唯一目标）。元贡献：证明对约束语言 PPL/BLEU 单独认证无效，必须上结构感知诊断。

## 3. 独立信息论结果（满足"每篇有独立公式"红线）

### 3.1 续写（已落地 §8.4）
定义每步 KL 预算 `b_t = KL(q_t ‖ p_t)`。EGD 以门控使 `b_t` 跨步近似恒定（非在近确定步浪费、平坦步爆发）。
**Lemma 1（放大因子）**：在近确定步 / 平坦步二分类近似下，top-k 的最坏步失真被放大 `1/(1−α)`，其中 `α` = val 集 `p_max ≥ 0.9` 步占比。实测 `α = 0.3627 → 1/(1−α) = 1.569`。该近似在 `α→1` 最敏感（已写入 Limitations）。

### 3.2 摘要扩展：生成失败的**两层分解**与 Theorem 3.2′（取代已证伪的 Theorem 3.2）

> v6 曾以 Theorem 3.2 声称「`v_0(L)` 随 `L` 减小而单调上升」；七档长度扫**证伪**了该速率形式（证伪证据完整保留于 §3.2.2 与 §6.5，不删）。
> 本节给出**取代它的正面定理** —— 不是描述性的经验规律，而是 definition / theorem 级、且**已被数据证实**的可检验结果。

**记号.** 藏文音节语法 `G`（确定性槽位语法 `syllable_slots_v3`）：音节为槽位元组，合法性 = 满足槽位约束。记音节字母表 `Σ`，上下文 `c` 下的合法集 `A(c) ⊆ Σ`。生成摘要 `S = (s_1,…,s_L)`，`L` 为音节预算；`Y` 为任务相关信息（摘要须保留者）；模型 `M` 的音节级条件分布为 `q_θ(·|c_j)`。

**Definition 1（正字法违反指示与 ISR）**
`e_j ≜ 1{ s_j ∉ A(c_j) }`,  `ISR(S) ≜ (1/L) Σ_{j=1}^{L} e_j`.

**Definition 2（字形接地赤字 γ）** 在 top-1 / beam MLE 解码下
`γ(M) ≜ E_{c∼C} [ 1{ argmax_{s∈Σ} q_θ(s|c) ∉ A(c) } ]`
（采样解码下取质量式 `γ_mass(M) ≜ E_c[ q_θ(Σ \ A(c) | c) ]`，二者同向）。
`γ(M)` 仅由 **(词表, 预训练权重)** 决定 —— 即模型的**字形接地**程度。

**Definition 3（生成失败的两层分解）**
- **语义 / IB 层**：压缩后任务信息保留多少。受 rate-distortion 支配 —— 为保留 `I(Y;S) ≥ i`，需 `L ≥ L_min(i) ≜ i / h_eff`（`h_eff` = 藏文每音节有效信息量）。可测：ROUGE-L / BLEU-4 / chrF（语义重叠）与**产出量**（音节产出数、压缩率）。
- **正字法 / 字形层**：音节是否合法。受 `γ(M)` 支配。可测：ISR / SCR。

**结构性要点.** IB 约束 `I(Y;S) ≥ i, |S| ≤ L` 作用在 **token / 语义流**上；而音节正字法合法性是对 token 的**字形实现**的约束，位于 IB 语义层**之下（sub-token）**。故两层由不同对象支配（`L_min(i)` vs `γ(M)`）且**渐近独立** —— 这是本节的实质主张。

**Theorem 3.2′（正字法瓶颈位于 IB 层之下：压缩不变性）**
假设
- **(A1)** token-MLE 解码（greedy / beam）：按 `q_θ(·|c)` 取 argmax / beam；
- **(A2)** **字形接地的位置平稳性**：合法集 `A(c_j)` 与"合法 vs 非法候选之间的序关系"由 `q_θ` 与 `G` 决定，不依赖位置 `j`，也不依赖剩余语义预算。

则对长度预算 `L`：
`ISR(M, L) = γ(M) + ε(L)`,  `E[ε(L)] = 0`,  `Var[ε(L)] = γ(M)(1 − γ(M)) / L`,
即 `ISR(M,L) = γ(M) + O_p(L^{−1/2})`，**无系统性单调漂移**。记压缩率 `ρ`（随 `1/L` 增大），则
`∂ ISR(M) / ∂ρ ≈ 0`,  `Δ_ortho(M) ≜ ISR(M) − ISR(human) ≈ γ(M) − ISR(human)`.

> **→ 正字法赤字对压缩预算不变，且仅由基座的字形接地决定：压缩既不能诱发、也不能修复它。**

**证明梗概.** 在 (A1) 下 `e_j = 1 ⟺ argmax_s q_θ(s|c_j) ∉ A(c_j)`。由 (A2)，`{e_j}` 为（近似）可交换的 Bernoulli 变量，共同均值 `γ(M)` —— 预算 `L` 只约束"选哪些内容"（IB / RD 层，受 `L_min(i)=i/h_eff` 支配），并不改变字形层上合法 vs 非法的序关系。故 `ISR = (1/L)Σ_j e_j` 是可交换指示变量的样本均值：由 Hoeffding 不等式得 `ISR − γ(M) = O_p(L^{−1/2})`，且期望为 0（**无漂移项**）。∎

> **诚实声明（不可删）.** (A2) **不是**由第一原理导出的，它是本定理的实质断言，由 §3.2.2 的七档长度扫**实证验证**。被证伪的 Theorem 3.2 预测的正是那个"漂移项"；长度扫拒绝了该漂移项，从而把 claim 从"压缩伤害正字法"翻转为更强的"**正字法失败位于压缩层之下**"。

**Corollary 3.3（跨任务不变性 · 任务适配不可修复性）**
因 `γ(M)` 仅为 `(词表, 预训练权重)` 的函数：
- **(i) 跨任务不变**：在压缩—生成轴上（续写 vs 摘要）预测 `ISR_cont` 与 `ISR_sum` 同量级、且均 ≫ 人类 → 实测 Qwen 0.0648 / 0.0462；TiLamb 0.004 / 0.0051 ✅
- **(ii) 对任务适配鲁棒**：低秩适配器可重塑语义条件（任务相关），但在冻结的基座嵌入张成空间内**无法创建**基座词表中不存在的合法音节流形 → `γ` 不变。实测 Qwen+LoRA 0.0462；换正确 chat template 重训仍 0.035 ✅
- **(iii) 对 prompt 格式鲁棒**：`γ` 是解码层属性，无格式依赖 ✅

**几何注记.** 合法藏文音节在发射单纯形上占据一个**测度稀疏且结构化的子集**（槽位填充受组合约束）。"字形接地" = 基座嵌入空间中存在一个相干子流形，其经 LM head 的像集中于该子集。在未接地的基座中，藏文码位散落于 byte-fallback 与跨脚本共享区域（实测与 Odia / Lao / Devanagari 系字形共现），该流形不存在，argmax 无法被约束到其上 → 赤字在**地板处饱和**，与预算无关。

### 3.2.2 实证支持（七档长度扫 `T∈{32,48,64,96,128,192,256}`，BodSUM n=150，beam=4）

| 模型 | ISR 范围（幅度） | 相对人类 0.0043 | Spearman(压缩率, ISR) |
|---|---|---|---|
| TiLamb+LoRA（已接地） | 0.0041–0.0082（2.0×） | 0.9×–1.9× | −0.821（方向合，幅度小） |
| Qwen+LoRA（未接地） | 0.0401–0.0539（**1.35×**） | **9.3×–12.5×** | **+0.643（反向）** |

- **① γ 平稳性的直接证据 —— 音节产出随预算线性增长，而违反率恒定**：TiLamb `mean_gen_syll` 20.4→153.2（7.5×），ISR 仅 2.0× 波动且**非单调**；Qwen `mean_gen_syll` 6.5→42.5（6.6×），ISR 仅 **1.35×**。→ 违反数随音节数**线性累积**，而**每音节违反率恒定** —— 恰是 Theorem 3.2′ 中可交换 Bernoulli / 位置平稳 γ 的图像。
- **② 同实验内的解离（两层分离的直接证据）**：预算强烈影响"**说多少**"（`compression_syll`：TiLamb 0.058→0.411，7.1×；Qwen 0.017→0.114，6.7×），却几乎不影响"**说得多合法**"（ISR 波动仅 1.35× / 2.0×）。→ **IB 层（产出量 / 内容）对预算敏感；字形层（合法性）对预算不敏感。**
- **③ 预算挪用：跨脚本发射首次量化**（补 §6.(7) 的"未量化"缺口）：同预算下藏文音节产出效率 `syll/token` —— TiLamb 153.15/256 = **0.598**，Qwen 42.53/256 = **0.166**（差 3.6×）→ Qwen 约 **72%** 的生成预算被非藏文（中译 / 跨脚本乱码）占用。这把原先"预训练/词表缺藏文生成能力"的**定性**诊断首次**量化**。
- **④ 伪影已排除**：各档 `truncation_rate≈1.00`，故补做人类摘要截断对照（`human_trunc_control.py`，CPU）：人类参考按同长度硬截后 ISR 仅 **0.0040–0.0047**，而 Qwen 各档 **0.040–0.054（≈10×）** → 截断伪影解释不了。

### 3.2.3 可证伪预测（把 claim 变强，供 future work）

- **P1**：对任意未接地基座，ISR 对 `L` 平坦（幅度 ≲1.5×），与语言 / 领域无关。
- **P2**：`γ` 在同一轴线的不同生成任务间不变（Corollary 3.3(i) 的推广）。
- **P3（判别性，最重要）**：**同时重训嵌入 / 分词器**（即改变词表）的全参微调**可**降低 `γ`；在冻结嵌入上的低秩适配器 / 追加任务数据**不能** → 这条把本理论与"再多 LoRA 数据就能修"区开，是最有力的后续实验。
- ⚠️ 当前长度扫仅记录正字法与产出量指标（ISR/SCR/`mean_gen_syll`/压缩率），**未记录 chrF/ROUGE 逐档值**，故"语义指标随 `L` 变化"这一支尚未在同实验内直接验证 → 列入 future work（可复用 `task3_len_sweep.py` 加 `--metrics chrf,rouge` 重跑）。

## 4. 跨任务实证（中心点，已校准 → 判定 ✅ SUPPORTED）

ISR 由**确定性藏文音节槽位语法判定器**（`syllable_slots_v3.parse`）计算，已在 **3.6M 人类音节**校准：新闻 ISR≈0.6%、续写参考 ISR≈0.4%、SCR≈0.88 → **判定器不过杀合法藏文**（详见 `data/task3/isr_calibration.json`）。故：

| 模型 | 续写 ISR↓（零样本） | 摘要 ISR↓（同款 LoRA 后） | 解读 |
|---|---|---|---|
| Llama-3.1-8B-Instruct | **0.269** | —（未跑摘要） | 通用零样本最差 |
| Qwen2.5-7B-Instruct | 0.0648 | **0.0462** | 通用，两任务均崩；摘要侧对 LoRA 鲁棒 |
| TiLamb-7B-LoRA | **0.004** | **0.0051** | 藏文专门化，两任务均≈人类 |
| 人类基线 | 0.00384 / 0.0057 | 0.00384 / 0.0057 | 续写/摘要两个校准口径 |

> 注：Qwen 摘要 ISR 0.0462 已用探针排除「格式 artifact」——base Qwen2.5-7B-Instruct + 正确 chat template 零样本对 5 条真实 BodSUM 正文生成，仍系统性失败（多数翻成中文、吐跨脚本乱码 Odia/Latin/老挝文，mean ISR 0.035）。根因 = Qwen2.5 **预训练/词表缺藏文生成能力** + **跨脚本词元病理**，非接口级 mismatch。故 Qwen+chat-template 重训无必要，原 ISR 0.0462 为忠实结果。

5. **§3.2 长度依赖子推论 → 已证伪、撤回，并由 Theorem 3.2′ 取代**（v6.1，2026-10-07）：七档长度扫显示通用模型 ISR 与长度预算**基本无关**（全程波动仅 1.35×）且方向**与预测相反**（Spearman **+0.643**）；专门化模型方向符合（**−0.821**）但幅度仅 2.0×。故**不写** `v_0(L)` 单调上升，改为 **Theorem 3.2′（正字法瓶颈位于 IB 层之下、赤字对压缩率不变）**。
   - **属自我证伪，如实写入**（与 §5 方法论诚实一致），证伪证据保留于 §3.2.2。
   - ⚠️ Theorem 3.2′ 的假设 **(A2)（字形接地的位置平稳性）非由第一原理导出**，它是本定理的实质断言、由长度扫实证验证；正文须明示此点，不得写成"已证明"。
   - ⚠️ 长度扫未记录逐档 chrF/ROUGE，故"语义层随 `L` 变化"这一支未在同实验内直接验证（见 §3.2.3 末条）。
6. **人工母语者打分（G2）缺失（P0，用户侧）**：生成质量结论限于结构/重叠指标（ISR/SCR/BLEU/chrF），不含语义偏好胜率。
7. **Qwen 失败根因已部分量化**（v6.1 更新）：原"预训练/词表缺藏文生成能力"属定性诊断；现以**藏文音节产出效率 `syll/token`** 量化 —— TiLamb 0.598 vs Qwen 0.166（3.6×），即 Qwen 约 **72%** 生成预算被非藏文占用（§3.2.2 ③）。**仍未量化**的是 token 级嵌入分布 / 跨脚本码位共现的细粒度分析，及 `γ` 的直接估计（需逐位置合法性标注），列 future work。
