**(7)【新增·rev4｜2026-09-28 已按实测结果改写，措辞不得回退】**
TiNews 给出藏文续写的**标准解码协议**与**截断偏差分析框架**。我们证明截断解码相对模型分布引入的偏差恒等于 `KL(q_t‖p_t) = −log Z_t`（Z_t 为截断 support 的概率质量），并据此给出可证伪推论：top-p 是唯一保持**常数 KL 预算**的截断族，而 top-k 的预算随分布尖锐度波动，在近确定步占比为 α 的语料上其最坏步失真被放大 1/(1−α) 倍。

**实测支撑（须照此写）**：在 TiLamb-7B 上，49,674 个 teacher-forced 步实测 α = 0.3627（→ 放大因子 **1.569**）；top-k 的每步 KL 显著高于 top-p（**0.0587 vs 0.0342**），且其预算波动远大于 top-p（高熵/低熵比 **330× vs 4.2×**），与推论一致。

**同时如实报告的反证（不得省略）**：我们原先预测"采样类解码在藏文上的流畅性代价（ISR）高于 beam 类"，**该预测未获支持**——实测采样 ISR（0.0044–0.0046）并不高于 beam（0.0045–0.0055）。此反证须写入 §7.4.5。

> ⚠ **写作红线**：贡献点 (7) **不能**写成"我们对比了 8 种解码策略"。对比本身不是贡献，**恒等式与放大因子 1/(1−α) 才是**。若 reviewer 只看到一张扫描表，会判定为工程报告。
> ⚠ **第二红线**：不得以 ISR 差异作为本贡献点的证据（已被证伪）；亦不得声称 EGD 全面最优（EGD 的 BLEU 低于 top-p+T=0.7）。EGD 的定位见 §8.4.7。

### 六、Evaluation Protocol

**6.1 分类任务** — 同 rev3（6.1.1 四种上下文设定 / 6.1.2 指标 / 6.1.3 三层基线 / 6.1.4 特征）。

**6.2 续写任务**

**6.2.1 任务定义**：给定前 k 句，生成第 k+1 句；句子级归一化 PPL。

**6.2.2【rev4 新增·必须写明的澄清】PPL 不经过解码。**
> 句子级 PPL 是 **teacher-forcing 下的条件似然**：`PPL = exp(−(1/|y|) Σ_t log p_θ(y_t | x, y_{<t}))`，其中 `y_{<t}` 是**参考前缀**而非模型自回归输出。因此 PPL **与任何解码策略无关**，不存在"用哪种解码算 PPL"的问题。
>
> 这一澄清必须显式写入正文，原因有二：(a) reviewer 与读者极易混淆似然评测与生成评测；(b) 它自然引出本文的关键区分——**teacher-forced 似然 ≠ 生成质量**，二者必须在协议上分离报告（见 §6.3、§7.4）。

**6.2.3 人工评测**：四项（流畅性 / 连贯性 / 信息量 / 藏文正字法正确性），1–5 分。

**6.3【rev4 新增】Canonical Decoding Protocol（标准解码协议）**

**6.3.1 为什么 benchmark 必须写死解码协议**
一旦报告任何基于生成文本的指标（BLEU / chrF / BERTScore / 人工评测），解码策略即成为**混淆变量**：同一模型在 greedy 与 top-p=0.95 下的 BLEU 差异常大于模型间的差异。Benchmark 的核心价值是可比性与可复现性，因此必须规定唯一主协议，并把它与"解码策略分析"（§7.4）严格分离——前者是规矩，后者是分析。

**6.3.2 主协议（主表所有生成指标一律采用）**

| 项 | 取值 |
|---|---|
| 方法 | Beam search, **B = 4** |
| `length_penalty` | 1.0（不做长度偏置修正，保证与参考长度可比） |
| `no_repeat_ngram_size` | 3（藏文重复退化严重，见 §7.4 rep-n 列） |
| `max_new_tokens` | 参考句长 p95 上取整（按分句统计确定，写作时填入实测值） |
| EOS | 遇 `།` 或换行终止 |
| 随机性 | 确定性，**不采样** |
| seed | 42 |

> 选 beam=4 而非 greedy 或 top-p：greedy 多样性过低（distinct-2 塌陷），top-p 在**单参考** BLEU 下被系统性低估（本基准每条续写仅有 1 条参考，见 §11），二者都不适合作为唯一主协议。beam=4 在 BLEU 与流畅性之间稳定折中，且完全确定性、零 seed 敏感性。

**6.3.3 藏文特有的生成流畅性诊断量**

| 量 | 定义 | 作用 |
|---|---|---|
| **ISR** (Invalid Syllable Rate) | `1 − 符合藏文音节正字法的音节数 / 生成音节总数` | 采样解码是否产出不合法/不闭合音节串 |
| **SCR** (Syllable Closure Rate) | 以 `་`(tsheg) 或 `།` 正确终止的音节占比 | 藏文音节边界完整性 |
| **E[−log Z_t]** | 平均截断 KL 预算（§8.4 Lemma 1） | 解码相对模型分布的系统性偏离 |
| **KL_p99** | 逐步 `−log Z_t` 的 99 分位（最坏步失真） | 检验 Proposition 3 的放大效应 |

> **实现说明（已校准，2026-09-30）**：ISR/SCR 由**确定性藏文音节槽位语法判定器**（`syllable_slots_v3.parse`）计算——按 前加字/上加字/根字/下加字/元音/后加字/再后加字 七槽位解析每个音节，非法即计 `inv`。该判定器已在 **3.6M 人类音节**上校准：新闻正文 ISR≈0.6%、续写参考 ISR≈0.4%、SCR≈0.88，**证明判定器不过杀合法藏文**（详见 `data/task3/isr_calibration.json`）。中心点统一用 **ISR（非法音节率）**，不用 `1−SCR` 的"违反"松口径（后者混入了"合法但无元音/后加字"的音节）。78 个边缘槽位组合仍在专家审校中（见 Limitations §11）。

**6.3.5【rev4 补充·必须写明】藏文生成指标的 token 化约定**
> 藏文**没有词间空格**，BLEU 的 token 单位不唯一，不同切分下的 BLEU **不可比**。本文约定：
> - **BLEU-4 一律按音节切分**：以 `་`(U+0F0B, tsheg) 为分隔符切出音节，剔除句末标点 `།`；
> - **chrF++ 使用字符级**（byte-level 回退），不依赖切分，作为跨切分可比的稳健指标；
> - 论文与开源代码中**必须显式声明上述切分方式**，否则后续工作无法与本文数字对齐。
>
> 这也是本文把 **chrF++ 列为主指标之一**、而非只用 BLEU 的原因。

**6.3.4 人工评测的执行约束**
> 人工评测必须**只在主协议（beam=4）生成的样本上**执行。若人工评测样本来自采样解码，则评分结果依赖 seed 不可复现，且会混入采样噪声，无法与自动指标对齐。

**6.4【Task 3 新增·2026-09-30】藏文新闻摘要与关键词抽取（Summarization & Keyword Extraction）**

**6.4.1 任务定义与两个子基准**
TiNews 新增 Task 3，覆盖新闻理解的"全局压缩"与"要素抽取"。数据由两部分互补构成（详见 `TiNews_task3_spec.md`）：
- **3a 生成式摘要（主评测集 BodSUM-6000）**：给定 `Text` → 生成 `SUM`；清洗后 5945 条（train 5351 / test 594），单篇、标准、干净。
- **3b 关键词抽取（扩展集 Ti-SUM）**：给定 `body` → 抽取 `keywords`（། 分隔多标签）；可用 734 条（26% 缺失，须注明覆盖率）。
- **3c 聚类 / 多文档摘要（扩展集 Ti-SUM）**：给定同聚类多文档 → 生成事件摘要（`title` 作参考）；按聚类切分，test 90 条。

**6.4.2 互补性（为何两个集都要）**
BodSUM-6000 提供"标准、干净、单篇、大规模"的主摘要基准（统计力强、结论可靠）；Ti-SUM 补 BodSUM 缺失的**关键词抽取**与**同事件多文档摘要**维度，且形态更贴近真实新闻聚类。二者不冗余、互补，统一归入 Task 3。

**6.4.3 防泄漏切分**
BodSUM 单篇无聚类 → 随机 90/10（seed 20260930）；Ti-SUM 按 cluster(文件) 切 90/10，同事件不跨集。BodSUM 已做正文精确去重（54 条重复新闻）。

**6.4.4 评测协议（复用 §6.3 口径）**
BLEU-4（音节切分，§6.3.5）、chrF++、ROUGE-L、ISR/SCR（藏文正字法，§6.3.3）、可选 COMET（G5）；解码统一 §6.3 主协议（beam=4, no_repeat_ngram_size=3, length_penalty=1.0, seed=42）。跨 tokenizer 用 bits/藏文字节 桥接（同 §6.8）。关键词抽取用音节级 F1 / ། 分隔集合 Jaccard。

**8.4【rev4 新增·理论核心】截断解码的 KL 偏差分析**

**8.4.1 记号**
第 t 步模型条件分布 `p_t(y) = p_θ(y | x, y_{<t})`，词表 `V`。截断解码选取 support `S_t ⊆ V`，并在其上重归一化得实际生成分布：

```
q_t(y) = ( p_t(y) / Z_t ) · 1[ y ∈ S_t ],    Z_t = Σ_{y ∈ S_t} p_t(y)
```

**8.4.2 Lemma 1（截断偏差恒等式）**

```
KL( q_t ‖ p_t ) = − log Z_t
```

**证明**：
```
KL(q‖p) = Σ_{y∈S} q(y) log( q(y)/p(y) )
        = Σ_{y∈S} (p(y)/Z) log( (p(y)/Z) / p(y) )
        = Σ_{y∈S} (p(y)/Z) log(1/Z)
        = −log Z · (1/Z) Σ_{y∈S} p(y)
        = −log Z .   ∎
```

> **解读**：截断解码相对模型的偏差**只由被保留的概率质量 Z_t 决定**，与词表大小、保留 token 的身份无关。这是一个极干净的单参数刻画。

**8.4.3 Corollary 1（greedy 的偏差即其 NLL）**
greedy 对应 `S_t = {ŷ_t}` 的退化情形，`q_t = δ_{ŷ_t}`，故
```
KL(q_t ‖ p_t) = − log p_t(ŷ_t)
```
恰为该步的负对数似然。因此 **greedy 生成序列的累计截断偏差 = 该序列的 teacher-forced 总 NLL**。这解释了 greedy 为何在单参考 BLEU 与 PPL 上表现一致最优，同时在多样性上必然最差——它把全部偏差预算用于最大化似然，没有剩余预算用于探索。

**8.4.4 Proposition 2（top-p 的常数预算性质）**
top-p 取满足 `Z_t ≥ P` 的最小概率降序前缀。则 `KL_t = −log Z_t ∈ [0, −log P]`，且在尾部分布连续时 `Z_t → P`，故

```
KL_t → − log P     （常数，与 t 无关）
```

top-k 固定 `|S_t| = k`，`Z_t = Z_t(p_t)` 依赖于分布的尖锐度，其 KL 预算随 t 波动。

**8.4.5 Proposition 3（top-k 的最坏步放大）**
设语料中近确定步（`p_max ≥ 1−ε`）占比为 α，其余为平坦步。在**相同的期望 KL 预算**下：

```
KL_worst(top-k) = ( 1 / (1 − α) ) · KL_worst(top-p)
```

**推导**：top-k 在近确定步上 `Z ≈ 1`、`KL ≈ 0`（预算被浪费），在平坦步上预算全部集中释放，设其 KL 为 `L_B`；则 `E[KL]_topk = (1−α)·L_B`。top-p 全程 `KL ≡ L_P`，`E[KL]_topp = L_P`。令二者期望相等：
```
L_P = (1−α)·L_B  ⟹  L_B = L_P / (1−α)
```
两边的最坏步 KL 分别为 `L_B` 与 `L_P`，故放大因子为 `1/(1−α)`。∎

> **可检验推论**：α 越大（近确定步越多），top-k 的最坏步失真越被放大。藏文音节级生成中，句末 `།`、固定套语、音节内部高度可预测的位置占比很高，预期 α 显著偏大 → **预测 top-k 在藏文上的 ISR 高于 top-p**。α 可直接从 val 集 teacher-forced 的 `p_max` 分布实测（取 `p_max ≥ 0.9` 的步占比）。

**8.4.6 EGD（Entropy-Gated Decoding）——理论导出而非工程拼凑**
由 Lemma 1，合理的解码应使 `KL_t` 在各步间保持**近似恒定**，而非让它在近确定步浪费、在平坦步爆发。据此定义门控解码：

```
mode(y<t) =  argmax              if  H(p_t) ≤ θ_low
             sample from S*(h*)  if  H(p_t) ≥ θ_high
             beam-B              otherwise
```
其中 `S*(h*) = argmin_{|S|} { S ⊆ V : H( p_S / Z ) ≥ h* }` 为最小充分 support。

**θ 不通过网格搜索标定**，而是取 val 集 teacher-forced 熵分布的**分位数**（建议 `θ_low = q20`，`θ_high = q80`），保证零额外超参、完全可复现。

> ⚠ 与 §2 红线一致：EGD 的价值来自 Lemma 1 导出的"恒定 KL 预算"原则，不是来自"又一个门控 trick"。写作时必须先给原则，再给算法。

**8.4.7 EGD 实测与受限口径（2026-09-28 定稿）**

α 实测 **0.3627**（val 集 49,674 个 teacher-forced 步中 `p_max ≥ 0.9` 的占比）→ **1/(1−α) = 1.569**；θ = (q20, q80) = (0.0904, 3.2079)。

### 十一、Limitations
> 同 rev3 全部条目，另补：
- **本基准每条续写仅有 1 条参考句，单参考 BLEU 对采样类解码存在系统性低估**，因此本文同时报告 chrF++ 与多样性指标（distinct-n、ISR 等），且主协议不使用采样。BERTScore（基于 CINO 句向量）受单参考约束且本期未实算，与多参考 BLEU 一并留待未来工作。
- **ISR 由确定性藏文音节槽位语法判定器计算，已在 3.6M 人类音节上校准**（新闻 ISR≈0.6%、参考 ISR≈0.4%、SCR≈0.88，证明不过杀合法藏文）；78 个边缘槽位组合（26 冲突 + 52 未现，见 `syllable_tables/crosscheck_*.csv`）仍在专家审校中，定稿后绝对 ISR 可能微移，但**模型 vs 人类基线的相对比较稳健**，论文结论不受影响。
- §8.4 的放大因子 1/(1−α) 在"近确定步 / 平坦步"二分类近似下导出，真实分布为连续谱；该近似在 α 接近 1 时最为敏感。
