# 藏文生成评测指标调研 + TiFMS 指标提案
> 调研日期：2026-09-15 ｜ 目标：确定 TiNews 续写任务的评测指标
> 结论：**现有藏文生成工作全部借用通用指标（BLEU / chrF++ / ROUGE / TER），无一藏文专属指标 → 存在真实空白，可自设。**

---

## 一、现状调研：藏文生成/翻译到底在用什么指标

| 工作 | 时间/venue | 任务 | 所用指标 | 关键表述 |
|---|---|---|---|---|
| **TFD**（Tibetan Foundation Dataset, arXiv 2503.18288v7） | 2025–2026 | 藏文翻译 + **藏文故事生成** | 翻译：BLEU-4 + chrF++；**生成：ROUGE-1 / ROUGE-2 / ROUGE-L** | "chrF++ ... suitable for morphologically rich and low-resource languages such as Tibetan" |
| **SSPA**（藏英/藏医药翻译, MDPI Computers 15(9):576） | 2026 | 藏英 NMT | BLEU-4（核心）+ **TER** + **chrF++**，sacreBLEU 实现；人工 5 人 + Fleiss' κ + paired t-test | **"BLEU 依赖词级 n-gram 硬匹配，对藏文这种黏着语的形态变化极不敏感；单个格助词误用会改变整句核心关系"→ 故以 chrF++ 为关键补充** |
| **DiRec**（藏汉 NMT, CCL 2025） | 2025-08 | 藏汉翻译 | BLEU + chrF++ | — |
| **MiLiC-Eval**（ACL 2025, arXiv 2503.01150） | 2025 | 藏/维/哈/蒙 LLM 基准，9 任务，含 **Headline Generation 1000 条** | 自动指标（生成任务沿用 BLEU/ROUGE 系） | 首个中国少数民族语言 LLM 标准化基准 |
| **CMiLBench**（ACL 2026 long） | 2026 | 藏/蒙/维，17 任务 | **自动指标 + LLM-as-a-Judge 混合框架** | 新一代趋势：自动指标已不够 |
| **FTibSuite**（Findings ACL 2026） | 2026 | 藏文 VLM | **DeepSeek-V3 作 LLM-judge**，rubric = accuracy(0-2) + completeness(0-2) + **藏文语言自然度(0-1)** | **明确把"decoding configuration"列为评测协议标准化的三要素之一** |

### 三条可直接写进论文的观察

1. **藏文生成任务的现行事实标准 = BLEU-4 + chrF++（翻译）/ ROUGE（生成）**，且已有工作**明确指出 BLEU 对藏文形态不敏感**（SSPA），但所有人的补救办法都只是"再加一个 chrF++"，**没有人针对藏文提出新指标**。
2. **没有任何藏文工作使用 COMET / XCOMET / MetricX / BERTScore**。原因很实在：COMET 系需要 MQM 人工标注训练，藏文没有；XLM-R 对藏文覆盖极差，零样本不可靠。**这是一个真实的、由数据稀缺造成的空白。**
3. **"解码配置标准化"已被 FTibSuite（ACL 2026）明确列为评测协议的一部分** → 我们 rev4 §6.3 的 Canonical Decoding Protocol **有 2026 年 ACL 工作背书，不是自说自话**。这一条要引用。

### 支撑性文献（用于论证我们为什么按音节切、为什么抓格助词）
- **Shi et al., CCL 2017**（Springer）：藏文句法功能块识别**以音节为单位而非分词**，预处理阶段显式抽取 **syntactic markers**，并区分 **sticky written form（粘写）与 non-sticky written form（分写）** → 直接支撑"音节 + 功能标记"的技术路线。
- **Liu et al., CCL 2015**："Tibetan text is written without natural word delimiters"；缩写音节（abbreviated syllable）普遍存在 → 佐证按 tsheg 切音节是合理且必要的 token 单位。
- **青海师大《藏语词性标注规范 V1.0》**（Gya & Tsering, IATS 2010）：格助词（རྣམ་དབྱེ་）为**独立封闭词类**，标注码 `g` → 我们把格助词单独拎出来做指标，有国家标准级别的词类依据。

## 二、空白在哪：现有指标对藏文的三重失配

| 失配 | 说明 |
|---|---|
| **① token 化歧义** | 藏文无词间空格，BLEU 的 token 单位不唯一（字符/音节/词），不同切分不可比 |
| **② 形态不敏感** | 格助词、时态、名物化等承载句法关系，词级 n-gram 硬匹配抓不住（SSPA 已指出） |
| **③ 正字法不可判定性浪费** | **藏文音节构成是可判定的**（前加字/上加字/根字/下加字/元音/后加字/再后加字有明确组合约束），而现有指标**完全没有利用这一免费的正确性判据**，全都在做字符串比对 |

> 第 ③ 点是最关键的：**藏文给了你一个无需参考文本就能判定对错的结构约束，而 BLEU/chrF/ROUGE 全都要参考。** 这是藏文相对英文的"信息红利"，没人用。

## 三、TiFMS：Tibetan Form–Morphology–Semantics Score

### 3.1 设计原则（先定原则，再给公式——顺序不能反）

1. **三个分量必须正交**：分别对应子音节形式层、句法功能层、内容序列层。
2. **全部不依赖神经模型**：COMET/BERTScore 在藏文上不可靠且不可复现，规避之。
3. **聚合必须有原则，不能加权求和**：加权系数无法论证 → 用调和平均，理由见 Lemma 2/Prop 4。
4. **至少一个分量是 reference-free 的**：这是相对所有现有指标的质的区别。

### 3.2 记号
- `y*` 参考句，`ŷ` 生成句
- 音节切分：以 tsheg `་`(U+0F0B) 分隔，剔除句末 `།`
- `σ(y)` = y 的音节序列，`|σ|` = 音节数

### 3.3 分量一：Φ — 形式合法性（**reference-free**）

藏文书面音节构成：
```
音节 ::= [前加字] [上加字] 根字 [下加字] [元音符号] [后加字] [再后加字]
前加字 ∈ {ག,ད,བ,མ,འ}      上加字 ∈ {ར,ལ,ས}
下加字 ∈ {ྱ,ྲ,ླ,ྭ}          元音 ∈ {ི,ུ,ེ,ོ}   （缺省为 a）
后加字 ∈ {ག,ང,ད,ན,བ,མ,འ,ར,ལ,ས}   再后加字 ∈ {ད,ས}
```
组合约束（示例，需完整编码）：再后加字 `ད` 仅接后加字 `ན ར ལ` 后；`ས` 仅接 `ག ང བ མ` 后；前加字与根字有固定搭配表；上加字与下加字不得冲突等。

**双轨实现**（两者都报，互为鲁棒性检查）：

| 轨 | 判定方式 | 偏差方向 |
|---|---|---|
| **Φ_rule** | 正则自动机编码上述组合约束，合法音节 → 1 | **保守**：罕见但合法的约束未编码 → 可能高估 ISR |
| **Φ_lex** | 从 TiNews 10,484 篇真实新闻提取音节表（约 400 万+ 音节），未登录音节 → 非法 | **激进**：合法但语料未现 → 可能低估 ISR |

```
Φ(ŷ) = 1 − ISR(ŷ),    ISR(ŷ) = 非法音节数 / |σ(ŷ)|
```
主指标用 **Φ_rule**，Φ_lex 作为敏感性分析，并报告两者的一致率与分歧样本。

### 3.4 分量二：K — 句法功能标记 F1

格助词（རྣམ་དབྱེ་）是**封闭类**，可完整枚举，且承载藏文主要句法关系。

提取流程（分两步，处理粘写/分写两种形式，对应 CCL 2017 的 sticky / non-sticky）：
1. **分写形式**：音节 ∈ 助词表 → 直接命中
2. **粘写形式**：音节 ∉ 表，尝试后缀剥离 —— 若 `s = p ⊕ m`（m 为粘写助词，p 去掉 m 后仍是**合法音节**，依 Φ_rule 判定）→ 命中 m

助词表（按青海师大词类规范，写作时需定稿）：
```
属格/作格 ：གི་ གིས་ ཀྱི་ ཀྱིས་ གྱི་ གྱིས་ འི་ ཡི་ ཡིས་
位格/与格 ：ལ་ ན་ སུ་ ཏུ་ དུ་ རུ་
从格/比较 ：ལས་ ནས་
连属/强调 ：དང་ ནི་ ཡང་ འང་
持续/连接 ：ཏེ་ སྟེ་ དེ་ ཅིང་ ཞིང་ ཤིང་
名物化   ：པ་ བ་ པོ་ པའི་ བའི་
引述/句末 ：ཅེས་ ཞེས་ ལོ་ འོ་ སོ་
```

```
K(ŷ, y*) = 多重集 F1( M(ŷ), M(y*) )
M(·) = 该句提取出的功能标记多重集；   多重集 F1 = 2Σmin(c_ŷ, c_{y*}) / (Σc_ŷ + Σc_{y*})
```

> **关键**：K **不需要分词器**。按 tsheg 切出的音节天然把助词独立成 token——这与 §6.3.5 的"BLEU 按音节切"约定完全自洽，构成方法上的闭环。

### 3.5 分量三：Σ — 内容保真

```
Σ(ŷ, y*) = chrF++(ŷ, y*) / 100     （sacreBLEU 标准实现，字符级，β=2）
```
选 chrF++ 而非 BERTScore：藏文无 COMET 训练数据、XLM-R 覆盖差，chrF++ 是 SSPA / TFD / DiRec 三家共识。**同时报 ROUGE-L（音节级）作为敏感性检查**。

### 3.6 聚合

```
TiFMS(ŷ, y*) = 3 / ( 1/Φ + 1/K + 1/Σ )      ，任一分量为 0 时 TiFMS ≡ 0
```

**为什么是调和平均而不是加权求和**：加权系数无法论证，属工程拼凑。调和平均是 F-score 向三维的自然推广，其语义是**"任一维度崩塌则总分崩塌"**，恰好对应藏文生成"形式合法 + 格标记正确 + 内容相关"三者必须同时成立的语言学事实。这不是选择，是约束。

## 四、可证明的性质

**Lemma 2（界）**：设 `m = min(Φ,K,Σ)`，`M = max(Φ,K,Σ)`，则
```
m ≤ TiFMS ≤ min(3m, M)
```
*证*：`S = 1/Φ+1/K+1/Σ ∈ [1/m, 3/m]`，故 `TiFMS = 3/S ∈ [m, 3m]`；又 HM ≤ AM ≤ M。∎

**Lemma 3（零吸收）**：`TiFMS = 0 ⟺ min(Φ,K,Σ) = 0`。
即：生成非法音节 / 格助词全错 / 内容完全无关，**任一条成立即判 0**（内容再像也不给分）。BLEU 无此性质。

**Proposition 4（最弱分量优先，诊断性）**：
```
∂TiFMS/∂x = TiFMS² / (3x²)      ，x ∈ {Φ, K, Σ}
```
*证*：`∂(3/S)/∂x = −3/S² · ∂S/∂x = −3/S²·(−1/x²) = 3/(S²x²) = (3/S)²/(3x²) = TiFMS²/(3x²)`。∎

> 边际收益与分量当前值的**平方成反比** → 改善最弱维度收益最大。**TiFMS 的梯度天然指向最该修的那个维度**，这是诊断型指标，不只是打分器。BLEU 的几何平均作用于同维度不同阶，无此正交诊断性。

**Proposition 5（参考无关分解 · 核心差异）**：Φ 不依赖 `y*`。因此对**任意无参考的生成语料 C**，`Φ(C)` 可独立计算，用作**零样本模型退化检测**（如扫 100 万条生成语料、监控解码参数病态、无需任何参考答案）。BLEU / chrF / ROUGE / COMET **全部依赖参考，均无此能力**。

## 五、验证方案（不给这个，reviewer 一定不认）

新指标被接受的唯一门槛：**与人工评分的相关性显著优于现有指标**。

| 项 | 设计 |
|---|---|
| 样本 | 主协议 beam=4 生成结果中抽 **200 条**（与 §7.4 的 500 条子集同源） |
| 评分者 | **3 名藏语母语者**（与分句标注同一批，Kappa 0.87 的风格基础） |
| 维度 | 流畅性 / 连贯性 / **正字法正确性** / 信息量，1–5 分（正字法维度专为验证 Φ） |
| 一致性 | 报告 **Fleiss' κ** |
| 相关性 | Pearson / Spearman / Kendall τ，对 BLEU-4、chrF++、ROUGE-L、TiFMS、以及 Φ / K / Σ 各分量 |
| 系统级 | 成对判别准确率（pairwise accuracy） |
| 显著性 | **bootstrap resampling × 1000** 给出 95% CI；指标间差异用 **Williams' test**（或 paired bootstrap） |
| 额外分析 | 报告 Φ / K / Σ 三者间的相关矩阵，**若高度相关则需在 Limitations 说明并讨论 TiFMS 的增量价值** |

## 六、风险与撤回条件（必须预先写死）

| 风险 | 应对 |
|---|---|
| ISR 规则不能穷尽藏文组合约束 | 主用 Φ_rule，同时报 Φ_lex 与分歧率；Limitations 明示为近似 |
| 粘写助词剥离出错 | 报告剥离命中率；错误案例分析进附录 |
| chrF++ 与 Φ/K 信息重叠 | 报分量相关矩阵；若重叠严重，讨论 TiFMS 的增量 |
| **相关性不优于 chrF++** | **⚠ 硬性撤回条件**：若 TiFMS 与人工评分的相关性未显著超过 chrF++，则**不得主张新指标**，降级为"三个补充诊断量"放在分析节，撤回贡献点 |
| 只在藏文类音节文字有效 | 明确写出适用范围：藏文、宗卡语、缅甸、老挝、高棉等具可判定音节结构的文字；不宣称通用性 |

## 七、论文落位与两档方案

### 方案 B（保守，推荐先做）
不发明新指标名。在 §6.3.5 后加 **§6.3.6 藏文专属诊断量**：只报 **ISR**（Φ 的补）与 **CaseF1**，与 BLEU-4 / chrF++ / ROUGE-L 并列成表。
- 优点：零风险，不可能被攻击"你发明了个没人用的指标"
- 缺点：novelty 弱

### 方案 A（激进，需人工评测支撑）
新增 **§6.4 TiFMS 定义** + **§8.5 与人工评分的相关性验证**，并加贡献点。
- 前置条件：**必须完成第五节的人工评测并跑赢 chrF++**，否则不写

> **我的建议**：脚本两个都实现（成本几乎相同，Φ 和 K 本来就要算），**论文先按方案 B 写**，等人工评测结果出来，若 TiFMS 显著胜出再升级为方案 A。这样进可攻退可守。
