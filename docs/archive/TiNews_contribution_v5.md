## 0. 一句话 thesis（整篇论文立在这句）

通用大模型在藏文新闻上存在**系统性的结构级失败**——它们违反藏文音节正字法、且压缩失当；而这种失败用常规 PPL / BLEU **根本看不见**。TiNews（诊断台）+ IB/KL 解码框架（理论）把它**暴露并解释**。

卖点是**一个可被证伪的科学主张 + 一套解释它的理论**，不是"我们做了 3 个任务"或"数据集更大"。

## 2. 故事五幕（按此顺序讲）

**① 动机：现有评测的盲点。** 藏文是低资源、强正字法约束语言。现有基准只"训分类器/算 BLEU"，证不出模型是否真懂结构。实证锚点：Llama 续写 PPL 最低（1.99）却 26.9% 音节非法（ISR 0.269）。→ 立论：**PPL 低 ≠ 藏文好**（呼应"KL 小 ≠ 质量好"红线）。

**② TiNews 不是 3 个任务，是"压缩—生成主轴"的 4 个探针。** 分类=能否读结构；续写=能否局部生成且守音节约束；摘要=能否全局压缩且守约束+保信息；关键词=能否抽信息骨架。强调是**同一轴线在 4 个粒度上的采样** → unified testbed，非数据集拼盘（摘掉"工程组合"指控）。

**③ 理论：IB/KL 解码框架（独立公式见 §3）。** 把生成看成"长度约束下的信息瓶颈"，藏文音节约束是额外结构罚。续写的 KL 预算（§8.4）推广到摘要（全局压缩），给出可检验的下界。

**④ 实证：跨任务系统性失败（全文高点）。** 通用模型在**续写与摘要两任务**上 ISR/SCR 都崩（续写：Llama ISR 0.269；摘要侧同构复算）→ 不是单任务偶然，是**系统性结构盲点**。同时如实写：困惑度仍通用更低 → 主动杀掉"专门化整体优于通用"claim，改讲"通用模型有可测结构缺陷，小专门化模型能补上"。

**⑤ 意义：可迁移 + 方法论诚实。** TiNews 是**诊断框架**不是 leaderboard——leaderboard 会过时，诊断方法能迁移到任意低资源约束语言（藏文是 case study，非唯一目标）。元贡献：证明对约束语言 PPL/BLEU 单独认证无效，必须上结构感知诊断。

## 3. 独立信息论结果（满足"每篇有独立公式"红线）

### 3.1 续写（已落地的 §8.4）
定义每步 KL 预算 `b_t = KL(q_t ‖ p_t)`。EGD 以门控使 `b_t` 跨步近似恒定（非在近确定步浪费、平坦步爆发）。
**Lemma 1（放大因子）**：在近确定步 / 平坦步二分类近似下，top-k 的最坏步失真被放大 `1/(1−α)`，其中 `α` = val 集 `p_max ≥ 0.9` 步占比。实测 `α = 0.3627 → 1/(1−α) = 1.569`。该近似在 `α→1` 最敏感（已写入 Limitations）。

### 3.2 摘要扩展（**新，待 Task 3 实验验证**——本稿核心增量）
把摘要 `S` 视为文档 `D` 在长度约束 `|S| ≤ L`（音节数）下的压缩表示。
- **下界（rate-distortion）**：为保留类可预测互信息 `I(Y;S) ≥ i`，所需最短音节数满足
  `L ≥ L_min(i) ≜ i / h_eff`，
  其中 `h_eff` 为藏文有效每音节信息量。即：压得越短，能保留的任务信息越少。
- **结构罚（正字法违反下界）**：token-MLE 解码器最小化 CE，不约束槽位语法。当 `L → L_min(i)`（最大压缩）时，解码器被迫进入低概率（稀有）音节区，槽位合法性更不确定，故
  `v(S) ≥ v_0(L)`，且 `v_0(L)` 随 `L` 减小而**单调上升**。
  而结构感知/专门化解码器（在藏文上训练）的音节先验尊重槽位语法，`v(S) ≈ v_human`（≈0.004）基本不随 `L` 变。
- **可检验推论**：Task 3 摘要生成中，令摘要长度 `L ∈ {短,中,长}` 变化测 ISR——通用模型应 `ISR↑` 随 `L↓`，TiLamb-LoRA 保持 ≈0.004 平坦。该现象即 Theorem 3.2 的经验证据，也是把 §8.4 从续写推广到摘要的桥梁。

> 标注：3.2 是**预测 + 待验证**，不写进正文结论直到 Task 3 实验跑出。但它已给出清晰的"独立公式 + 信息论视角"，满足红线对"数学建模 > 工程组合"的要求。

## 4. 跨任务实证（中心点，已校准）

ISR 由**确定性藏文音节槽位语法判定器**（`syllable_slots_v3.parse`）计算，已在 **3.6M 人类音节**校准：新闻 ISR≈0.6%、续写参考 ISR≈0.4%、SCR≈0.88 → **判定器不过杀合法藏文**（详见 `data/task3/isr_calibration.json`）。故：

| 模型 | 续写 ISR↓ | 摘要侧（待 Task 3） | 解读 |
|---|---|---|---|
| Llama-3.1-8B-Instruct | 0.269 | 同构复算预期崩 | 通用零样本系统性失效 |
| Qwen2.5-7B-Instruct | 0.0648 | — | 居中 |
| TiLamb-7B-LoRA | 0.0043 ≈ 人类 0.00384 | 近人类 | 专门化学到结构 |

中心点口径锁定为 **ISR（非法音节率）**，弃用 `1−SCR` 的"91% 违反"松表述（已在大纲 §6.3.3 / G1 .tex / ledger §6.8 同步）。

## 5. 定位与方法论诚实

- **diagnostic testbed，非 leaderboard**：寿命长、可迁移到任意具可判定音节结构的文字（宗卡语、缅甸、老挝等）。
- **元贡献**：对约束语言，PPL/BLEU 单独认证无效，必须结构感知诊断。这是审稿人尊重的"诚实方法论"贡献。
- **自我证伪已做**：§7.4.5 采样 ISR 高于 beam 的预测被证伪，已如实写入，未改数据迎合。

## 6. Limitations（写死，非遮掩）

1. **非 comprehensive**：NER/MT/QA/多模态/方言/事实一致性未覆盖（见 §1）。
2. **BodSUM-6000 部分预存**：贡献是整合 + 防泄漏整理 + 跨任务诊断，非数据发明。
3. **Ti-SUM test 仅 90 条**：统计力弱；其意义在补关键词+多文档维度，不在大。
4. **ISR 判定器**：78 个边缘槽位组合（`crosscheck_conflicts.csv` 26 + `crosscheck_unseen.csv` 52）仍在专家审校中；已校准，模型 vs 人类基线的相对比较稳健，但绝对 ISR 可能微移。
5. **摘要在 §3.2 的定理待 Task 3 实验验证**，未证实前不入结论。
6. **人工母语者打分（G2）缺失时**：生成质量结论限于结构/重叠指标（ISR/SCR/BLEU/chrF），不含语义偏好胜率。
